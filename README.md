# Гостиница «Ольга»

Одностраничный сайт гостиницы в Краснодаре. React, TypeScript, Vite, Tailwind CSS, Motion и Lucide. Реальные фотографии, галерея, интерактивная карта и бронирование по телефону.

## Загрузка в GitHub

Распакуйте архив. Загрузите **содержимое папки olga-github**, включая `.gitignore` и `.nvmrc`, в корень своего репозитория. В корне должны находиться `package.json`, `index.html`, `src/`, `public/` и `scripts/`. Сам ZIP загружать вместо файлов не нужно.

Архив содержит исходники, конфигурацию и все фотографии, необходимые для сборки. `node_modules/` устанавливается командой ниже, `dist/` создаётся при сборке. Ключей доступа и файлов окружения в комплекте нет. Загрузка исходников в GitHub сама по себе не публикует работающий сайт.

## Локальный запуск

Нужны Node.js 24 LTS и pnpm 11.25.0. В терминале из корня проекта:

```sh
pnpm install --frozen-lockfile
pnpm dev
```

Открыть http://127.0.0.1:4185. Остановка — Ctrl+C.

## Сборка

```sh
pnpm build
node scripts/serve.mjs
```

Сборка проверяет TypeScript и создаёт `dist/`: статический HTML, JS/CSS, изображения, локальные шрифты, Hotel JSON-LD, robots.txt, sitemap.xml, Open Graph и 404.html. Сервер проверки работает на http://127.0.0.1:4185 и возвращает настоящий 404 для неизвестных путей.

Пока сервер запущен, во втором терминале:

```sh
node scripts/check.mjs
```

## Редактирование

- `src/config/hotel.json` — контакты, стоимость, оснащение, отзывы, ссылки на карты и домен.
- `src/config/photos.json` — фотографии, группы и alt-тексты.
- `src/App.tsx` — секции и взаимодействия.
- `src/styles.css` — оформление и адаптивность.
- `public/photos/` — 11 отобранных фотографий в JPEG и WebP, уже готовых к сборке.

Стоимость не фиксирована; по умолчанию показывается «Стоимость уточняйте по телефону». Отзывы не выдуманы: пустой список показывает ссылку на Яндекс Карты. Чтобы добавить настоящий отзыв, используйте объект `name`, `text`, `sourceUrl` в `reviews`.

Удобства на снимках относятся к отдельным студиям; одинаковое оснащение всех номеров не заявляется. Заявки через формы, онлайн-оплата, CMS и база данных не используются. Кнопки бронирования открывают звонок администратору.

Логотип и часть заголовков предназначены для гостиницы «Ольга»; для переименования также измените `src/App.tsx`, `index.html` и генератор OG в `scripts/finalize.mjs`.

## Фотографии

Для обычной установки и сборки оригиналы не нужны: все подготовленные изображения включены. Скрипт `scripts/photos.mjs` служит только для повторной оптимизации исходных 22 файлов владельца и требует путь к их папке:

```sh
node scripts/photos.mjs "/путь/к/оригиналам"
```

Оригиналы не включены. Не запускайте скрипт без них и не очищайте массив фотографий: пустой набор требует отдельного состояния галереи.

## Публикация

1. Укажите реальный HTTPS origin без пути в `siteUrl` файла `src/config/hotel.json`.
2. Запустите `pnpm build`.
3. Передайте содержимое `dist/` статическому хостингу с размещением сайта в корне домена.
4. Проверьте HTTPS, карту, маршруты, звонок на телефоне и настоящий HTTP 404.

До настройки домена сборка содержит `noindex,follow`, пустой sitemap и не задаёт вымышленный canonical. После настройки домена метаданные и sitemap формируются автоматически.

Версия настроена для GitHub Pages по адресу https://ckot228.github.io/olga.io/. Загрузите содержимое архива в корень репозитория, включая скрытую папку .github. В Settings → Pages → Build and deployment → Source выберите GitHub Actions. В Actions запустите Deploy website to GitHub Pages через Run workflow либо сделайте новый коммит. Сборка и публикация выполняются автоматически.

Сайт не опубликован. Аппаратный телефонный звонок и свайпы на физическом устройстве отдельно не проверялись.
